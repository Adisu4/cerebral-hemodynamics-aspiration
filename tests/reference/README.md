# Regression fixtures

These three files preserve the audited parameter, equation, and integration
implementation byte for byte. The manifest records their original names and
SHA-256 hashes. They are loaded only by regression tests; run the study using
the installed package under `src/`.

Internal historical identifiers remain unchanged to preserve the source hashes.
The earlier standalone study scripts and figures remain available in Git history
at commit `daaa0ff817ba75f58e6abe6cffabea261d5157e0`.
