# Publication figures

These files are generated by `cerebral-hemodynamics-plot` from the saved inputs
in `reference_results/figure_data/`. PDF files are editable vector graphics;
PNG files are 600 dpi. `figure_provenance.json` records SHA-256 hashes for the
visualization code, inputs, and outputs.

The Gadda comparison is a supine implementation-reproduction benchmark. It is
not independent validation of the intervention model or evidence of clinical
efficacy.
